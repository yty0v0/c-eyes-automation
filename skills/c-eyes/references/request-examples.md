# 请求示例

## 会被路由到 direct workflow skills 的请求

- “帮我直接扫一下 `.\target\webroot`”
- “帮我导出最近 24 小时的事件日志”
- “帮我先看这台机器整体情况”
- “帮我对 `/srv/www` 做 SBOM 盘点”
- “帮我做一次基线检查”

## 会被路由到 auto-triage 的请求

- “帮我排查这台主机为什么有异常”
- “帮我调查这个可疑目录相关的告警”
- “帮我分析最近的内网异常活动”
- “帮我排查为什么这台机器基线不过”

## 容易混淆的情况

### “帮我看这台机器有没有异常”

- 如果语气是“先快速看一下”，可先走 `c-eyes-host-triage`
- 如果语气是“排查/调查”，走 `c-eyes-auto-triage`

### “帮我看这个目录”

- 如果是直接扫风险，走 `c-eyes-filescan-risk`
- 如果是围绕告警做持续调查，走 `c-eyes-auto-triage`
